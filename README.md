# FolderSkin for Homebrew

Custom folder and drive icons from art, photos or AI. [folderskin.app](https://folderskin.app)

## The app

```sh
brew install --cask prajwal-svm/tap/folderskin
```

It updates itself. `brew uninstall --cask --zap folderskin` also removes its skins, settings and
the Local Model.

## The command line

```sh
brew install prajwal-svm/tap/folderskin-cli
```

Then run `folderskin --help`.

Both follow FolderSkin's releases on their own: a workflow here checks every three hours and moves
to a new version once its downloads are published and hashed.

The source is at [github.com/prajwal-svm/folderskin](https://github.com/prajwal-svm/folderskin).
